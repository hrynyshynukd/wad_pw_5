# Практична робота №5

Гринишин Вікторія ІПЗс-24-2

Тема: Дослідження архітектурних стратегій рендерингу веб-додатків: порівняльний аналіз багатосторінкових (MPA) та проєктування односторінкових (SPA) інтерфейсів.

## Висновок

Під час виконання практичної роботи було розглянуто відмінності між багатосторінковими (MPA) та односторінковими (SPA) веб-додатками. MPA передбачає завантаження нового HTML-документа під час переходу між сторінками, тоді як SPA дає змогу перемикатися між розділами без перезавантаження документа.

У проєкті реалізовано клієнтську навігацію між розділами за допомогою JavaScript та події `hashchange`. Також додано таймер, який продовжує працювати під час переходів, що демонструє збереження глобального стану застосунку. За допомогою інструментів розробника можна перевірити, що перемикання розділів не потребує повторного завантаження HTML-сторінки.

Отже, під час роботи було закріплено навички створення SPA-інтерфейсів, роботи з DOM і BOM та обробки подій засобами чистого JavaScript.
